# Cascadia documentation guidance

Use the [documentation index](README.md) for navigation. Keep setup and
verification commands aligned with `cascadia.py`, `pyproject.toml`, and
`uv.lock`. Keep conclusions about the tool's behavior grounded in code,
tests, or the synthetic example. Describe live provider data as mutable
inputs and keep its downloaded files out of Git.

The authored methods note lives in [manuscript/](manuscript/README.md). Use
the [pinned render guide](manuscript-build.md) to recreate its outputs.
